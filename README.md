# 一揽子股票组合分析系统

> 轻量级、零密钥、开箱即用的 A 股 / 港股 / 美股量化研究工具。基于 tkinter GUI，支持多因子评分、组合回测、个股诊断、系统托盘。

**当前版本**：v2.5  
**盈利目标**：创业板 + 20% Alpha（年化 25-35%，最大回撤 ≤ 25%）

---

## ✨ 功能特性

### 🎯 四层评分体系
- **宏观层**：PMI、M2、CPI/PPI、Shibor、地缘政治、战争、美元指数、纳指
- **政策层**：北向资金流向、融资融券余额变化
- **行业层**：行业轮动相对强弱、上下游产业链、突发新闻分类（军事/供应链/地缘政治）
- **个股层**：趋势、MACD、RSI、量价配合、波动率、技术形态识别

### 🏗️ 组合构建
- 评分加权 + 风险平价双权重方案
- 周度 + 信号触发双调仓频率
- 支持 10+ 只标的组合

### 📊 回测复盘
- 含佣金、印花税、滑点
- 整手/碎股适配（A股整手，港股碎股）
- 输出：净值曲线、交易记录、绩效指标、Markdown 报告

### 🔍 个股诊断器（8 维度）
- 股东数量变化 + 大单/超大单净流入
- 龙虎榜数据
- 股权质押比例
- 限售解禁数量
- 北向资金持股变化
- 融资融券余额变化
- 技术形态（上升/下降/横盘通道 + 突破/跌破）
- 综合场景判断（趋势 + 均线排列 + 双底双顶 + 支撑阻力）

### 📈 选股分析（17 类因子）
- 支持代码前缀、纯代码、中文全称、拼音缩写模糊查询
- 趋势分析、均线排列、双底双顶形态识别
- 支撑阻力位判断
- 综合场景输出（建议操作 + 置信度）

### 📰 新闻监控
- 财联社电报 + akshare 多源回退
- 自动分类：地缘政治、军事突发、产业链、其他
- 新闻最后获取时间戳 + 股票数据最后获取时间戳
- 支持按分类标签筛选

### 💻 GUI 界面（7 标签页）
| 标签 | 功能 |
|------|------|
| 📈 回测结果 | 净值曲线、绩效指标、交易记录 CSV |
| 🔍 实时监控 | 数据获取日志（颜色高亮：下载/完成/失败/跳过） |
| ⭐ 个股评分 | 四层评分雷达图 / 表格排序 |
| 📰 新闻监控 | 分类新闻展示 + 时间戳 + 影响分析 |
| 🎯 选股分析 | 17 类因子评分表格 + 双击指标折线图 |
| 🔬 个股诊断 | 8 维度诊断 + 基本信息 + 板块排名 + K线/筹码图 |
| ⚙️ 股票池管理 | 多选批量添加、拼音首字母匹配、多市场支持 |

### 🔔 系统托盘
- 最小化到托盘，不退出程序
- 双击托盘图标恢复窗口
- 右键菜单：恢复窗口 / 退出程序
- 事件触发时托盘图标闪烁 + 弹窗提示
- 自定义图标：窗口标题栏（钱包图标）、托盘默认（搜索图标）、事件闪烁（靶标图标）

## 🚀 快速开始

### 环境要求

- Python 3.10+
- pandas、numpy、matplotlib、requests、akshare、Pillow

```bash
pip install pandas numpy matplotlib requests akshare Pillow
```

### 启动 GUI

```bash
python portfolio_gui.py
```

### 运行回测（CLI）

```bash
# 单股回测
python portfolio_selector.py --mode backtest --pool sh.600519,sz.000858

# 生成报告
python portfolio_selector.py --mode report --pool sh.600519,sz.000858

# 新闻监控
python portfolio_selector.py --mode news
```

### 股票代码格式

支持多种输入格式：

- **A股**：`600519`、`sh.600519`、`sz.000858`
- **港股**：`00700`、`hk.00700`
- **美股**：`AAPL`、`us.AAPL`
- **中文/缩写**：`贵州茅台`、`茅台`、`gmt`、`gzm`

## 📐 四层分析框架

### Layer 1: 宏观
- 地缘政治冲突监测（战争/制裁/贸易摩擦）
- 经济周期指标：PMI（制造业扩张/收缩）
- 流动性：M2增速、Shibor利率
- 通胀：CPI/PPI剪刀差
- 全球风险：美元指数、纳指100

### Layer 2: 国家干预
- 北向资金流向（陆股通）
- 融资融券余额变化
- 产业政策关键词监测

### Layer 3: 行业
- 行业轮动相对强弱
- 行业估值分位（PE/PB）
- 上下游价格传导
- 库存周期位置

### Layer 4: 个股
- 趋势评分（MA5/MA20/MA60）
- MACD金叉/死叉信号
- RSI超买超卖
- 量价配合度
- 波动率（低波得分高）
- 技术形态（上升/下降/横盘通道、突破/跌破）
- 双底双顶形态识别
- 支撑阻力位判断

## 📦 输出说明

运行回测后会在项目目录生成：

- `portfolio_report_latest.md` — 投资策略报告
- `portfolio_equity_latest.csv` — 每日净值曲线
- `portfolio_trades_latest.csv` — 交易记录（含盈亏）
- `portfolio_chart_latest.png` — 净值曲线图
- `diag_{code}_diagnosis.png` — 个股诊断图表

## ⚠️ 风险提示

- 数据源为腾讯 ifzq 公开接口（免费），不做任何商业保证
- 港股数据通过 ifzq 的 `hk{code}` 格式获取，历史长度受接口限制
- 北交所、日股、韩股、台湾股、欧股数据暂未完全支持
- 回测结果仅供参考，不构成投资建议
- 参数优化存在过拟合风险，实盘前请用样本外数据验证
